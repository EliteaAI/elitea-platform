# env-drift allowlist for the elitea-main chart, consumed by
# services/elitea-llm-gateway/scripts/env-drift-check.sh (which checks both
# deployed Go services). One name per line; blank lines and # comments ignored.
# An allowlisted var is never a FAIL and is not reported as drift.
#
# The rule going forward: any NEW env var elitea-main starts reading must either
# appear in this chart's values.yaml `env` map (the whole map is rendered into
# the ConfigMap) or be added here WITH a justification. Everything below is the
# PRE-EXISTING baseline that predates this gate — it is not an endorsement, and
# entries should migrate to values.yaml as each is wired up.

# --- Secrets: must never be plaintext in a ConfigMap; supplied out-of-band via
# --- a Kubernetes Secret / platform injection.
APPLICATION_SECRET_KEY
SECRETS_MASTER_KEY
OIDC_CLIENT_ID
OIDC_CLIENT_SECRET
# GOOGLE_APPLICATION_CREDENTIALS (S17): deliberately NOT wired as a chart
# secretKeyRef, unlike AZURE_STORAGE_KEY/S3_ACCESS_KEY/S3_SECRET_KEY (which
# moved to values.yaml's secrets: block below — see deployment.yaml). GCS's
# intended production path is GKE Workload Identity (serviceAccount.
# annotations, added this stage), which needs no credentials file at all;
# an explicit key-file env var is the emulator/non-GKE fallback, not the
# baseline this chart should force every deployment to wire.
GOOGLE_APPLICATION_CREDENTIALS

# --- Identity provider endpoints, injected with the OIDC credentials above.
OIDC_ISSUER_URL
OIDC_REDIRECT_URI

# --- Object-storage backend selection + per-backend settings (S2, S5, S12) now
# --- wired directly in values.yaml's `env` map (plain) and `secrets` map
# --- (AZURE_STORAGE_KEY, S3_ACCESS_KEY, S3_SECRET_KEY) — removed from here as
# --- no longer drift. GCS_BUCKET and AZURE_STORAGE_CONTAINER, previously
# --- listed here, were never read by elitea-main under those names at all
# --- (the code reads STORAGE_CONTAINER for every backend); removed rather
# --- than carried forward as unused entries.

# --- Filesystem paths baked into the container image (Containerfile), not
# --- per-deployment configuration.
ADMIN_UI_STATIC_DIR

GATEWAY_SERVER_NAME
